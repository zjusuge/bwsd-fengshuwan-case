# Results

`fengshuwan_bwsd_results.xlsx` is the unchanged reference workbook from the earlier public release. Its simplified evidence flags and pre-formal components reflect that release; use newly generated outputs for the explicit S1 eligibility/timing fields.

`reference/` contains checked numerical tables, an audit report and a regenerated overview. `generated/` is ignored by Git and created by the CLI. Separate output directories are recommended for each Monte Carlo policy. Numerical reference values describe hydrological state and input uncertainty; they are not event-warning accuracy.
